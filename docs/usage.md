# 使用说明

[返回 README](../README.md) · [安装与更新](../INSTALL.md) · [Windows 支持边界](../WINDOWS.md)

## 日常流程

1. 在新 Codex 会话中从侧边栏打开插件。页面读取已有配置与本地模型目录，不自动请求供应商、不发起推理、不写文件。
2. 检查连接状态；需要时选择其他已配置 provider。缺失配置时按页面指引处理，本工具不提供密钥或连接配置补填表单。
3. 点击**刷新供应商模型**，只 GET 当前连接地址前缀下的 `/models`。列表接口正常不等于所有模型都能直连。
4. 勾选需要保留的模型。原本地模型默认选中，供应商其他模型默认不选；搜索、分页和“只看已选”可辅助筛选，表头复选框覆盖全部筛选结果（含分页）。
5. 用行内设置图标编辑菜单名称、请求 ID、上下文窗口、思考等级和图片支持；隐藏模型可通过**手动添加模型**补充。重复 ID 不会覆盖已有模型，修改仅保留在当前草稿。
6. 点击**更新模型列表**。未知参数或重复 ID 会显示“未写入”，修正后再继续；校验通过才进入排序。
7. 调整顺序，按需**预览变更**，然后**确认写入**。也可在排序弹框中直接确认；关闭排序或预览均不写文件。
8. 写入或恢复后重启 Codex，使模型菜单及顺序生效。这与插件更新本身不一定需要重启是两回事。

刷新列表和检测结果轮询保留当前草稿；重新读取配置、重开页面或重建实例不保证保留编辑。取消勾选只改草稿，但最终确认写入的目录只包含本次选中的模型。

## 参数与直连检测

- 参数优先级为**本地目录 > 供应商声明 > 静态公开参考**，只补缺失字段，不覆盖本地手动设置；不根据模型名称猜测上下文或图片能力。未知值需手动确认。
- 新供应商模型的默认思考等级优先取支持列表中的 `medium`；不支持时取从低到高的中间档，偶数档取偏低档。支持列表未知或为空时不设置；本地默认值与已编辑草稿不受刷新影响。
- 上下文支持 `128K`、`1M`、精确 tokens 和固定步长增减；1K=1000、1M=1,000,000，上限 10M。修改前保留本地精确值。
- 静态参考来自 CC Switch v4.0.10 和 2026-10-13 的 models.dev 公开快照；按完整供应商部署路径匹配，唯一原厂引用可作后备。运行时不访问参考数据源，参考参数不是本连接实测。来源与哈希见 `src/catalog/reference-metadata.json`，许可随包分发。
- **Codex 直连**显示“未检测”“测试中...”“通过”“不满足直连”或“无法确认”；点击状态可检测或查看上次原因与流式证据，不展示供应商原始正文。编辑请求 ID 后使用新 ID 检测，没有路由模式。
- 单模型或批量检测均先列出目标、次数及 token 消耗说明，点击**确认并测试**才 POST `/responses`。每批最多 1000 个不同 ID，串行执行、固定短文本、`stream:true`、`store:false`、最多 64 输出 tokens；首事件超时 15 秒，总超时 30 秒，不自动重试。
- “通过”只证明本次基础文本 Responses 流有效，不证明图片、工具调用、所有思考等级或上下文长度可用。HTTP 200、`[DONE]` 或模型名称不能单独证明通过；鉴权、额度、限流和网络错误不直接等同于不支持。
- 取消本地请求不保证供应商未处理或未消耗 token；工具可见性不是密码学授权，完整宿主记录审计仍有未验证边界。

## 排序、写入与恢复

排序支持上移、下移、置顶和置底。预览单独显示目标、增删改、顺序变化及完整 JSON；退出预览会回到排序并保留当前顺序。预览后改序会使旧计划失效，提交时按最新草稿重新校验，不静默移除模型。

未经预览或提交的排序不会记住；预览或提交后，本页保留该顺序，刷新供应商不重置。新选择追加，取消勾选不进入 JSON；重新读取配置恢复本地目录顺序。写入同时更新 `models` 数组顺序和从 0 开始连续递增的 `priority`。

确认写入前检查配置与目录未发生变化、备份原文件，然后同步临时文件并原子替换。冲突时拒绝覆盖；失败时尽力回滚，状态不确定则停止并提示检查。保留原目录及模型的其他安全字段和自定义 instructions，新模型使用中性默认结构，不复制供应商长提示词。修改上下文会同步最大窗口并清除旧自动压缩阈值，仍需核对最终 JSON。

配置区的**写入记录与恢复**可查看最近操作时间、数量、目标和备份路径；**恢复上次写入**需再次确认，目标或备份改变时拒绝覆盖。记录只保留在当前后端实例，不是持久化历史；重启后仍可手动检查目标目录内的备份，备份不会自动删除。写入计划 5 分钟过期，确认端只接受后端生成的计划 ID 与请求 ID。

## 配置与安全边界

- 只写已配置的 `model_catalog_json`，不修改 `config.toml`、`auth.json`、连接、密钥或当前模型，不自动重启 Codex。官方安装器的插件注册/启用元数据变动与业务配置写入严格区分。
- 只复用同一 provider 的地址和凭据，不跨 provider 拼接。自动复用 HTTPS 与显式 Bearer；HTTP 需用户确认风险。账号标记与显式 Bearer 并存时使用 Bearer，不读取账号文件。
- 支持复用 `env_key` 指定的已有环境变量；缺失变量、鉴权命令、额外请求头/查询参数等不自动替代显式 Bearer，缺失或不支持时显示指引。
- 读取的是配置候选，不是完整 Codex 活动配置栈；不推定 CLI 覆盖、项目/系统/托管配置或宿主实际选择已知。
- 目录路径仅来自配置，不接受 UI 任意路径。支持绝对路径；主用户配置的相对路径以配置目录（默认 `~/.codex` 或 `CODEX_HOME`）解析，不受插件工作目录影响。
- 只读打开最终文件，拒绝最终符号链接、非普通文件、`auth.json` 和 TOML 文件；不对上级目录符号链接作额外防护承诺。Windows 的 NTFS、UNC、设备/ADS、权限与文件占用边界见 [WINDOWS.md](../WINDOWS.md)。
- 目录上限 2 MiB、最多 1000 个模型，校验 Codex 0.159.0 目录核心结构、重复 ID 和安全字段。无效或读取失败目录不能被预览替代；缺失或未配置目录可生成内存预览，但未配置目标时不能写入。
- 草稿与模型结果只在内存中；后端仅在当前实例复用密钥，不持久化或向 UI、聊天、工具结果返回完整密钥。不承诺擦除 JavaScript 内存或防御恶意宿主。
- Windows 写入强制同步备份/临时文件、原子发布并回读校验，回执为 `file_synced`，不承诺父目录项 fsync 或异常断电持久化；POSIX 同步文件与目录，回执为 `synced`。真实同步、权限或冲突错误仍阻止成功。

## 问题诊断

失败提示中展开**诊断信息**并复制给维护者；包含请求编号、插件/系统/Node 版本、阶段与白名单系统错误码，不包含原始异常、用户路径、配置、密钥或服务器正文。宿主不允许复制时会选中文本。

实际自动测试与团队验收分别记录在 [ACCEPTANCE.md](../ACCEPTANCE.md)。自动化、浏览器或 macOS 验证不等于原生 Codex 页面、Windows 或真实供应商验收。
